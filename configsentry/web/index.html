Find the weak spots in your network configurations.

Drop in a switch, router or firewall configuration. ConfigSentry shows each risky setting, the line it is on, and the commands that fix it.

    Privacy

    Network configurations are sensitive. ConfigSentry is built so they never leave your computer.

    It runs on this computer

    The app is a small local web server that only accepts connections from this computer (localhost). Nothing is sent to the Internet and there is no analytics.

    It never connects to your devices

    You upload or paste a configuration. ConfigSentry never logs in to switches, routers or firewalls and never asks for device passwords.

    Nothing is saved

    Configurations are read in memory to run the audit and are not written to disk. Archives are opened in memory too. A report is saved only when you download one.

    Secrets are masked

    Passwords, hashes, keys and SNMP communities are replaced with **** in results and reports. You can turn masking off on your own screen, but do not share screenshots or reports while it is off.

    Use it responsibly

    Only audit devices you own or are authorised to assess, and never commit real configurations to a public repository.
