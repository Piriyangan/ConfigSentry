# Security policy

## Reporting a vulnerability

If you find a security issue in ConfigSentry itself (for example, a way credentials or configuration
data could leak), please **do not open a public issue**. Contact the maintainer privately through
[LinkedIn](https://linkedin.com/in/piriyangan) or a GitHub private security advisory on this repository.

## Handling configuration data

- Never attach real device configurations, reports or credentials to issues or pull requests.
- Mask or replace hostnames, IP addresses, usernames and secrets before sharing any output.
